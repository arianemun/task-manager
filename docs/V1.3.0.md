# نسخه 1.3.0 — چت داخلی، اصلاح فاصله‌های موبایل/PWA، نسخه‌بندی

این سند فاز به فاز اجرا می‌شود. بعد از هر فاز گزارش داده می‌شود و تا تأیید، فاز بعد شروع نمی‌شود.

## قوانین کلی

- هر فاز در commit جدا. بعد از هر فاز `npm test`، `npm run lint` و `npm run build` سبز باشند.
- هیچ وابستگی به CDN یا سرویس خارجی در runtime. Firebase/FCM، Pusher، Ably و Supabase ممنوع.
- منطق تکرار، گزارش‌ها، دسترسی‌ها و چند دپارتمان تغییر نکند.
- قبل از migration روی سرور بکاپ دستی، و بعد `integrity_check` و `foreign_key_check`.
- متن UI در `lib/i18n/fa.ts`، تاریخ شمسی، اعداد فارسی، RTL طبق `docs/SPACING.md`.

## فاز ۰ — نسخه‌بندی، امضای سازنده، فاصله موبایل و PWA

نسخه این فاز patch است: `1.2.1`.

- منبع نسخه: `package.json`. در build، `NEXT_PUBLIC_APP_VERSION` و `NEXT_PUBLIC_APP_COMMIT` از `next.config`.
- `CHANGELOG.md` فارسی (Keep a Changelog) از tagهای `v1.0.0`، `v1.1.0` و `v1.2.0`.
- قانون `.cursor/rules/versioning.mdc` با `alwaysApply: true`.
- `npm run release -- <patch|minor|major>` نسخه را بالا می‌برد، بخش منتشرنشده را با تاریخ شمسی منتقل می‌کند، commit و tag می‌سازد و push نمی‌کند.
- نسخه و امضا در پایین `/me/profile` و پایین sidebar فقط در حالت باز. کلیک روی نسخه، تغییرات همان نسخه را در ResponsiveDialog نشان می‌دهد. قلب با keyframes ضربان (دو ضربه و مکث، ۱.۲ ثانیه) و در `prefers-reduced-motion` آرام‌تر، نه حذف.
- فاصله پایین: `--safe-bottom`، `--bottom-nav-h`، `--bottom-chrome`. safe area فقط یک‌بار در پایین‌ترین لایه. با کیبورد (`visualViewport`) bottom nav پنهان و safe area صفر. دسکتاپ بدون اثر.
- تست دستی در `docs/RESPONSIVE_TEST.md`.

## فاز ۱ — زیرساخت چت

سرور Socket.IO جدا در `realtime/` روی پورت داخلی (مثلاً ۳۲۳۱)، PM2 فورک تک‌instance. nginx مسیر `/socket.io/` را پروکسی کند. SQLite مشترک با `busy_timeout` حداقل ۵۰۰۰. احراز هویت با کوکی JWT و `sessionVersion`. مدل `conversations`، `conversation_members`، `messages`، `message_attachments`. پیام متنی با `client_id`، outbox، ریپلای، ویرایش ۱۵ دقیقه‌ای، حذف، و UI در `/chat`.

## فاز ۲ — حضور، نوشتن، خوانده‌شدن، اعلان درون‌برنامه‌ای

آنلاین با socket فعال، آفلاین ۱۵ ثانیه بعد از آخرین قطع. تیک ذخیره/تحویل/خوانده. Web Push در این نسخه نیست.

## فاز ۳ — عکس و ویدیو

آپلود Next، فشرده‌سازی عکس در کلاینت، ویدیو حداکثر ۱۰۰MB و ۵ دقیقه، magic bytes، ffmpeg سیستم‌عامل، صف `media_jobs`، Range 206 برای فایل.

## فاز ۴ — ویس

MediaRecorder، تبدیل سرور به AAC/M4A، نگه داشتن / لغو / قفل، waveform ذخیره‌شده.

## فاز ۵ — ویدیو مسیج دایره‌ای

حداکثر ۶۰ ثانیه، خروجی ۴۸۰×۴۸۰، پخش بی‌صدا در دید و با صدا با ضربه.

## فاز ۶ — امنیت، سلامت، بکاپ، استقرار، نسخه 1.3.0

بازبینی socket و routeها، db-check جدید، بکاپ جدا برای رسانه چت، `ecosystem.config.js`، README، تست‌ها، tag و push نسخه `1.3.0`.
