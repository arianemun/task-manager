# قاعده درصد گزارش

منبع واحد: `src/lib/reports/rates.ts` و `src/lib/reports/classify.ts`.  
`/me/report`، داشبورد، `/admin/reports` و تب گزارش `/admin/staff/[id]` از همین شمارش استفاده می‌کنند.

| وضعیت | درصد |
|---|---|
| `DONE`، `DONE_LATE` | صورت و مخرج |
| `NOT_DONE`، `MISSED` | فقط مخرج |
| `OVERDUE` (محاسباتی) | فقط مخرج. در DB همان `PENDING` می‌ماند. شرط: `due_at` گذشته باشد. ثبت بعدی اگر بعد از مهلت باشد `DONE_LATE` است. |
| `PENDING` با مهلت نرسیده | حذف از صورت و مخرج. جدا با برچسب «در جریان» |
| `EXCUSED`، `DONE_BY_PEER` | حذف از صورت و مخرج |

مخرج صفر → `null`. در UI «—» و توضیح «کار ارزیابی‌شده‌ای در این بازه نیست». در Excel سلول خالی.

بازه: `period_end` داخل `[from, to]`. اگر بازه امروز را شامل شود، دوره جاری هفتگی (`W:`) یا ماهانه (`M:`) با `period_end` بعد از بازه هم در «در جریان» می‌آید و فقط اگر مهلتش گذشته باشد در درصد (`OVERDUE`) حساب می‌شود.

کار `SHARED`: درصد گروه = دوره‌هایی که حداقل یک عضو `DONE` یا `DONE_LATE` دارد، تقسیم بر تعداد دوره‌های همان کار در بازه. این شاخص جدا از درصد فردی است.
