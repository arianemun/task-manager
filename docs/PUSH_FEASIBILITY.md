# امکان‌سنجی Web Push

آزمایش فاز P0. صفحهٔ جدا: `/admin/push-lab` (فقط مدیر کل). کلید VAPID محلی است. ارسال آزمایشی مستقیم بود و `PUSH_PROXY_URL` خالی ماند.

تاریخ آزمایش سرور: ۱۴۰۵/۰۷/۱۵. نتیجهٔ دستگاه‌ها همان روز ثبت شد.

## دسترسی سرور

درخواست نمونه: `GET /` با TLS و timeout هشت ثانیه. کدهای ۴۰۴، ۴۰۵ و ۴۰۶ یعنی اتصال و TLS برقرار است و ریشهٔ سرویس متد یا مسیر را قبول نمی‌کند.

| میزبان | مستقیم | با پروکسی |
| --- | --- | --- |
| `fcm.googleapis.com` | DNS و TLS برقرار، HTTP 404، حدود ۵۶۷ms | لازم نشد؛ پروکسی تنظیم نشده |
| `web.push.apple.com` | DNS و TLS برقرار، HTTP 405، حدود ۸۵۰ms | لازم نشد؛ پروکسی تنظیم نشده |
| `updates.push.services.mozilla.com` | DNS و TLS برقرار، HTTP 406، حدود ۵۶۲ms | لازم نشد؛ پروکسی تنظیم نشده |

## ماتریس دستگاه

ارسال از سرور مستقیم بود. کد HTTP دقیق هر ارسال گزارش نشد؛ «موفق» یعنی اعلان روی دستگاه دیده شد. ستون پروکسی آزمایش نشد چون پروکسی خاموش است.

VPN خاموش برای Android Chrome و وب‌اپ iPhone تست شد و اعلان رسید. اینترنت همراه، و رسیدن اعلان وقتی اپ کاملاً بسته است، هنوز تست‌نشده. جزئیات VPN در بخش بعد است.

## VPN

این نتایج بعد از ماتریس بالا ثبت شد.

- Android Chrome، VPN خاموش: اعلان رسید، بدون مشکل.
- Android، VPN روشن: اپ باز نمی‌شود. سرور ایران اتصال از IP خارجی را نمی‌پذیرد، پس اشتراک و تست انجام نشد. رسیدن push به دستگاهی که قبلاً مشترک شده و بعد VPN روشن کرده، تست‌نشده.
- iPhone وب‌اپ، VPN خاموش: اعلان رسید، بدون مشکل.
- iPhone وب‌اپ، VPN روشن: اعلان رسید، با کمی تأخیر.

## تصمیم

ارسال مستقیم پیش‌فرض است. `PUSH_PROXY_URL` در کد می‌ماند و خاموش است، تا اگر دسترسی سرور به سرویس‌های push قطع شد بتوان همان مسیر را بدون تغییر بقیهٔ ترافیک روشن کرد.

در فاز P5، db-check یا `/api/health` باید خطای پیاپی ارسال push را گزارش کند.

در فاز P2، چون iPhone فقط در وب‌اپ نصب‌شده Push می‌گیرد، راهنمای تصویری نصب اولویت بالا دارد: Share، بعد Add to Home Screen، بعد روشن بودن Open as Web App. در پروفایل، اگر کاربر iPhone از خود مرورگر آمده باشد، کارت «برای دریافت اعلان، اپ را نصب کنید» نشان داده شود. همان راهنمای نصب باید بگوید با VPN روشن اپ باز نمی‌شود و راه‌حل split tunneling است: مستثنا کردن `task.khanemadari.com` یا سایت‌های ایرانی. متن آماده در `docs/ADMIN_GUIDE.md`، بخش «کاربران دارای VPN» است. فازهای P1 به بعد بعد از انتشار ۱.۳.۰ شروع می‌شوند.
