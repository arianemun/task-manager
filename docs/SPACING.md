## لبه پایین موبایل

safe area فقط یک‌بار و فقط در لایه‌ای که به لبه viewport چسبیده اعمال می‌شود. توکن‌ها در `globals.css`:

| توکن | معنی |
|---|---|
| `--safe-bottom` | `env(safe-area-inset-bottom)` |
| `--safe-left` / `--safe-right` | لبهٔ فیزیکی چپ و راست؛ در همهٔ عرض‌ها، از جمله iPad و گوشی افقی |
| `--bottom-nav-h` | ارتفاع خود bottom nav، بدون safe area |
| `--bottom-chrome` | `--bottom-nav-h + --safe-bottom` فقط روی صفحه‌ای که bottom nav دارد؛ وگرنه صفر |
| `--keyboard-inset` | روی موبایل، وقتی کیبورد باز است؛ nav پنهان و safe area پایین صفر می‌شود |

از عرض ۷۶۸ به بالا فقط `--safe-bottom` صفر است. چپ و راست می‌مانند. این فاصله یک‌بار روی هدر، bottom nav، Drawer و کانتینر صفحه اعمال می‌شود.

## چت

صفحه گفتگو از فاصله فرم‌ها و کارت‌ها جداست و چگالی خودش را دارد. پس‌زمینه پیام‌ها توکن `--chat-bg` است، جدا از حباب.

| مورد | مقدار |
|---|---|
| صفحه گفتگو | تمام‌عرض و تمام‌ارتفاع؛ بدون `PageContainer`، `Card` یا padding صفحه |
| هدر گفتگو | ۵۶px؛ آواتار ۳۶px؛ نام ۱۵px وزن ۶۰۰؛ وضعیت ۱۲px و `muted` |
| حباب | padding افقی ۱۰px و عمودی ۶px؛ متن ۱۵px موبایل و ۱۴px دسکتاپ؛ line-height ۱.۵؛ حداکثر عرض ۷۸٪ موبایل و ۶۰٪ دسکتاپ؛ radius ۱۶px و گوشه ۴px سمت فرستنده روی آخرین پیام گروه |
| زمان و تیک | داخل حباب، گوشه پایین سمت end، ۱۱px، هم‌خط با آخرین خط اگر جا باشد |
| فاصله پیام | ۲px بین پیام‌های یک فرستنده؛ ۸px بین فرستنده‌های مختلف |
| آواتار پیام | در دونفره نیست. در گروه ۲۸px فقط کنار آخرین پیام هر گروه. نام فرستنده ۱۳px رنگی بالای اولین پیام گروه |
| جداکننده تاریخ | pill ۱۲px وسط، sticky هنگام اسکرول |
| composer | حداقل ارتفاع ۴۴px؛ دکمه‌ها ۴۰px و آیکن ۲۲px؛ متن فیلد ۱۶px در موبایل؛ گوشه گرد؛ ارسال و میکروفون دایره‌ای accent |
| ردیف فهرست | ۶۸px؛ آواتار ۴۸px؛ نام ۱۵px؛ پیش‌نمایش ۱۴px یک‌خطی؛ زمان ۱۲px؛ badge دایره‌ای کوچک؛ جداکننده فقط از کنار متن |
| رسانه | عکس هم‌تراز گوشه حباب و بدون padding داخلی؛ caption زیر آن داخل حباب؛ ویس حدود ۴۴px؛ آلبوم با فاصله ۲px |
| ورود پیام | ۱۵۰ms |

## کامپوننت‌های چیدمان

- `PageContainer` — padding و max-width صفحه
- `PageSection` — یک بخش با یک هدف
- `Stack` — فاصله عمودی استاندارد بین فرزندان
- `FormGrid` — شبکه/ستون فرم با gap فیلد ۲۰px
