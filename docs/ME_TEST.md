# سناریوی تست دستی — فاز ۶ (پنل پرسنل)

پس از `npm run db:reset` و تغییر رمز اجباری:

| کاربر | رمز | نقش |
|---|---|---|
| `admin` | از `.env` | ADMIN |
| `manager1` | `Manager@123456` | MANAGER |
| `staff1` | `Staff@123456` | STAFF |

ابتدا با admin چند کار روزانه/هفتگی/ماهانه به `staff1` (و در صورت نیاز به خود admin) اساین کنید و generate اجرا شود (باز کردن `/me` کافی است).

---

## ۱) صفحه امروز

1. با `staff1` به `/me` بروید.
2. کارهای باز در سه گروه «امروز / این هفته / این ماه» دیده شوند؛ هفته/ماه روز باقی‌مانده داشته باشند.
3. نوار پیشرفت «X از Y کار امروز» درست باشد.
4. «انجام شد» بدون note/attachment فوری ثبت شود (optimistic)؛ در صورت خطای شبکه وضعیت برگردد.
5. «انجام نشد» → bottom sheet با chipهای دلیل از `/admin/settings` + متن آزاد؛ بدون دلیل رد شود.
6. کاری با `requires_note` / `requires_attachment` → قبل از ثبت sheet باز شود؛ پیوست jpg بزرگ قبل از آپلود کوچک شود.
7. `completed_at` را در DB چک کنید — ساعت سرور باشد.
8. همان کار را ویرایش کنید → برچسب «ویرایش‌شده».
9. پس از پایان دوره (یا تنظیم period_end گذشته) دکمه‌ها قفل و فقط خواندنی شوند.
10. کار هفتگی `any_day_in_week` پس از ثبت، تا پایان هفته با همان وضعیت بماند و هر روز PENDING جدید نسازد.
11. معافیت/مرخصی → بخش خاکستری؛ اگر کل روز مرخصی است پیام «امروز در مرخصی هستید».
12. روز بدون کار → empty state.

## ۲) پیوست و امنیت

1. فایل >۵MB یا نوع غیرمجاز → خطا.
2. URL `/api/files/attachments/...` را با کاربر دیگر باز کنید → ۴۰۳.
3. ADMIN و MANAGER دپارتمان همان پرسنل بتوانند فایل را ببینند.
4. ثبت occurrence کاربر دیگر با دستکاری id → رد شود؛ دوره آینده رد شود.

## ۳) تقویم و گزارش

1. `/me/calendar` — ماه شمسی، هفته از شنبه؛ رنگ درصد انجام روزانه؛ تعطیل/مرخصی جدا؛ آینده بی‌رنگ.
2. کلیک روز → لیست کارها و وضعیت.
3. `/me/report` — درصد هفته/ماه، شمارنده‌ها، streak فعلی و بهترین، نمودار ۳۰ روز، لیست NOT_DONE/MISSED؛ بدون مقایسه با همکاران.

## ۴) اطلاعات، پروفایل، موبایل، نقش‌ها

1. اطلاعیه نخوانده → badge روی «اطلاعات» در منو؛ با باز کردن `/me/info` خوانده شود و badge کم شود.
2. یادداشت مدیر برای staff1 در اطلاعات دیده شود.
3. `/me/profile` — تغییر رمز و آواتار.
4. عرض ۳۶۰px بدون اسکرول افقی؛ bottom nav: امروز، تقویم، گزارش، اطلاعات؛ دکمه‌ها ≥۴۴px.
5. با `admin` / `manager1` لینک «کارهای من» در سایدبار ادمین به `/me` برود و کارهای اساین‌شده به خودشان را ثبت کنند.

## ۵) تنظیمات دلایل

1. `/admin/settings` (فقط ADMIN) — chip دلیل را اضافه/حذف کنید.
2. در sheet «انجام نشد» پرسنل همان لیست دیده شود.
